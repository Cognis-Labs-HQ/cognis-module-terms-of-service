# Rechtstexte

Lesen Sie veröffentlichte Rechtstexte und stimmen Sie deren aktuellen Fassungen ausdrücklich zu.

## Möglichkeiten

Öffnen Sie Rechtstexte über Fußzeilenlinks und prüfen Sie erforderliche Vereinbarungen. Administratoren können Entwürfe erstellen, Vorschauen öffnen, veröffentlichen und Zustimmungsberichte lesen.

## Vor dem Start

Öffentliche Rechtstexte sind ohne Anmeldung lesbar. Zustimmungen gehören zum angemeldeten Konto; Veröffentlichung und kontoübergreifende Berichte benötigen Administratorrechte.

## Erste Schritte

Öffnen Sie einen Rechtslink, lesen Sie den aktuellen Text und stimmen Sie bei Aufforderung ausdrücklich zu. Administratoren bearbeiten Entwürfe im Rechtstextbereich, prüfen die Vorschau und entscheiden über die Veröffentlichung.
