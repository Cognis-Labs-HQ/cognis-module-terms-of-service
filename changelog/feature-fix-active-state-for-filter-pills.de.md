# Sichtbare Filter für Zustimmungsberichte

**Feature-Branch:** feature-fix-active-state-for-filter-pills

## Ausgewählten Zustimmungsfilter anzeigen

Der Zustimmungsbericht zeigt jetzt genau eine Filter-Pill mit einer sichtbaren aktiven Darstellung und dem entsprechenden gedrückten Zustand an, damit Administratoren erkennen können, ob alle, akzeptierte oder ausstehende Konten angezeigt werden.
