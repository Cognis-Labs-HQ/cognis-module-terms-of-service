# 利用規約モジュール固有の識別情報

**機能ブランチ:** feature-fix-duplicate-uuid-issue

## 重複したモジュール UUID を修正

利用規約モジュール専用の恒久的な UUID を割り当て、Cognis が別のモジュールの複製として拒否しないようにします。

## モジュール識別情報を保護

割り当てた UUID の構造的な回帰チェックを追加し、モジュールのバージョンとパッケージのダイジェストを同期します。
