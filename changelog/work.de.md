# Öffentliche Rechtsdokumente ohne Anmelde-Shell

**Feature-Branch:** work

## Rechtsdokumente sind ohne Anmeldung verfügbar

Jede Rechtsroute verwendet weiterhin den Cognis-Seiten-Composer. Für Besucher ohne Anmeldesitzung unterdrücken Composer-Flags Kopfleiste, Navigation, Theme-Umschalter, Footer, Seitenkontext, Werkzeugleiste, Layout-Speicherung und Kontoerweiterungen, sodass nur das veröffentlichte, aus Markdown gerenderte Dokument sichtbar ist. Für authentifizierte Benutzer bleiben die bestehende Dokumentansicht mit vollständiger Shell und der Änderungsvergleich erhalten.
