## Declare required privileged access

The module manifest now declares privileged status so Cognis can enable the module when its administration and consent interfaces use the internal user directory, account-lifecycle endpoint, and protected checkbox style. The synchronized module standard documents why this access is required, and a structural test preserves the declaration.
