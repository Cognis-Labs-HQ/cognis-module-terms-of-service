# 使用例

公開された法的文書を読み、現在の版への同意を明示的に行えます。

## 前提条件

公開された文書はログインせずに読めます。同意はログイン中のアカウントに紐づき、公開やアカウント全体のレポートには管理者権限が必要です。

## 使用例

法的文書のリンクから現在の内容を読み、Cognis に求められた場合は明示的に同意します。管理者は文書の管理画面で下書きを追加・編集し、プレビュー後に公開するか判断します。

同意やその変更を行わず、法的文書とナビゲーションを紹介します。認証済みのオンラインセッションが必要です。

## 期待される結果

同意は公開された特定の版に対して記録されます。新しい必須版には再度の同意が必要で、ガイドやプレビューが代わりに同意・公開することはありません。

## 問題の解決

必要な同意にはオンラインでのサーバー確認が必要です。オフライン利用を拒否された場合は再接続して現在の条件を確認してください。文書のキャッシュだけでは同意の証明になりません。
