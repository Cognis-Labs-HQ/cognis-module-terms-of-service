# Dokumentasi dan Kontrak Host

**Cabang Fitur:** feature-documentation-core-alignment

## Dokumentasi terstruktur

Info, Penggunaan, dan Teknis menjadi keluarga dokumen terlokalisasi lengkap yang dideklarasikan manifes modul. Pengantar pengguna, prosedur praktis, serta kontrak API/konfigurasi memiliki tampilan terpisah. Pemeriksaan ketat susunan, referensi, dan nama berkas berjalan dalam pengujian mandiri serta CI. Tautan sumber mengikuti cabang bawaan; label tautan changelog memakai referensi komit singkat.

## Diagnostik gateway

Diagnostik runtime memakai gerbang logging host beserta kebijakan keluarannya. Laporan perintah memakai aliran terminal, dan pemeriksaan konsol native mencakup JavaScript modul, alias, serta akses terhitung. Kepemilikan penyedia, otorisasi, dan identitas penyelesaian tutorial tetap dipertahankan.

## Nama binding deskriptif

Validasi nama berbasis pohon sintaks memindai sumber JavaScript dan TypeScript, perkakas, pengujian, dan fixture tanpa daftar pengecualian lama atau pengecualian per berkas. Pemeriksaan mencakup binding waktu jalan, label parameter tanda tangan, anggota privat, serta nama tipe dan metode gabungan milik komponen. Bentuk singkat lazim tetap sah sebagai nama langsung seperti `db`, `this.db`, `args`, dan LDAP `dn`. Nama gabungan memperluas singkatan selain satuan ukuran, termasuk nama dari upstream: `DatabaseExecutor`, `KeyringDatabaseExecutor`, `createDatabaseExecutor`, `baseDistinguishedName`, dan `registerStaticDirectory`. Singkatan tidak jelas, pengganti bernomor, dan penggunaan binding yang diabaikan menggagalkan validasi. `_` yang tidak digunakan dan tidak diekspor, `id`, serta penghitung aritmetika `i`/`j`/`k` mempertahankan peran yang ditentukan. Parameter tipe generik, nama dependensi/platform kanonis, dan kunci muatan publik mempertahankan kontraknya. Deklarasi API, impor, ekspor, dan pemanggil milik komponen memakai nama yang konsisten; alias yang hanya mengganti nama, termasuk alias tipe, menggagalkan validasi. Fixture regresi melindungi perbedaan nama langsung/gabungan dan API platform kanonis. Manual teknis terlokalisasi, petunjuk kontribusi, versi modul, berkas kunci, dan hash paket diselaraskan. Token satuan ukuran seperti `ms`, `sec`, `px`, `rad`, dan `deg` tetap disingkat dalam nama gabungan; perluasan nama waktu dan piksel dikembalikan ke bentuk seperti `INVITE_EXPIRY_MS`, `timeoutMs`, dan `widthPx`. Fixture regresi menegakkan pengecualian satuan tanpa mengizinkan kata tetangga yang tidak jelas.
