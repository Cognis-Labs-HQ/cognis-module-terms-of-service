# 同意レポートフィルターの選択表示

**機能ブランチ:** feature-fix-active-state-for-filter-pills

## 選択中の同意フィルターを表示

同意レポートでは、フィルター Pill のうち常に1つだけを視覚的なアクティブ表示と対応する押下状態にし、管理者がすべて、承認済み、未承認のどのアカウントを表示しているか確認できるようになりました。
