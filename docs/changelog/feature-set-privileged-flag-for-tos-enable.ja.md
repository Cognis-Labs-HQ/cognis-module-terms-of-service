# Host リソースへの特権アクセス

**機能ブランチ:** feature-set-privileged-flag-for-tos-enable

## 必要な特権アクセスを宣言

管理画面と同意画面が内部ユーザーディレクトリ、アカウントライフサイクル Endpoint、および保護されたチェックボックス Style を使用する場合でも Cognis がモジュールを有効化できるよう、Module Manifest に特権状態を宣言しました。同期済みの Module Standard にこのアクセスが必要な理由を記載し、構造テストで宣言を維持します。
