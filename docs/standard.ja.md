# 利用規約モジュール標準

この文書は Cognis 利用規約外部モジュールがサポートするアーキテクチャを定義します。

## 公開コントラクト

モジュールは公開 SPA ルート `/terms-of-service`、`/privacy-policy`、`/eula` を登録します。Browser エントリーポイントはこれらの公開パスでのみ直接 Mount され、管理画面には `registerAdminSection` を通じてローカライズされた法務セクションを1つ追加します。認証 API ルートには必要最小限のロールを要求します。

公開された法的コンテンツは Cognis が `ui:reuse` を介して描画する Markdown です。保存するたびに `docs:versionStore` を介して不変バージョンを追記します。モジュールは Cognis 内部実装や特定のデータベースドライバーをインポートしません。

法的文書エディターは、折りたたみ可能な文書見出しと行内の追加・削除操作を備えた、全幅のコンパクトなカードグループを共有します。Cognis の情報ツールチップとフローティング変更追跡ユーティリティを使用します。エディターを追加すると、余白を備えたサイズ変更不可の Markdown 入力欄と、Messages Composer 形式の作成・プレビューボタンが表示されます。変更追跡の保存操作で更新を公開し、Host のトーストで成功を通知します。エディターの削除には確認が必要です。

## 同意とライフサイクル

各アカウントが同意した利用条件とプライバシーの正確なバージョンを記録します。登録では明示的な同意が必須です。認証セッション Flow は記録済みバージョンが最新でないアカウントをブロックし、同意時に両バージョンを記録し、拒否時にログアウトします。強制中も公開法務ページは閲覧できます。

スコープ付き登録はモジュール無効化時に削除されます。読み込み済みの Browser Hook が更新または再起動中にモジュールの同意 Endpoint が削除されたことを検出した場合、利用不能な Endpoint を記録し、以降の同意 Request を停止して、Navigation を妨げずに処理を終了します。文書と同意は無効化や再起動後も保持され、アンインストール時は `deleteContent` が真の場合のみ削除されます。ブラウザーリソースは `cognis.uiCtx` と Host のフィードバック、ナビゲーション、API、Popup、i18n、ページエントリの各コントラクトを使用します。

## リポジトリ品質

ルートの Manifest、Package、Lockfile、Route メタデータは常に同期します。Server コードは `api/`、Browser コードは `ui/`、運用コマンドは `cli/`、ローカライズ文書は `docs/`、リリースメタデータは `changelog/`、アートワークは `assets/` に配置します。テストはローカル Capability Fake を使用し、Route、永続化、Flow、ライフサイクル、ローカライズ、Package を検証します。
